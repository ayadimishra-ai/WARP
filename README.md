# Scripts

## 1. Run instances scripts

- Run hasura console script `yarn dev:hasura`
- Run directus app `yarn dev:directus`
- Run WARP web app `yarn dev:web`

## 2. Utility Scripts

- Graphql codegen `yarn codegen`

## 3. Other scripts

- Lint script `yarn lint`
- Prettier format script `yarn format`
- Build WARP web app script `yarn build`
